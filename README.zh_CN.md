# PICO UE5 身体追踪示例

- 如有任何问题/评论，请访问 [**PICO 开发者支持门户网站**](https://picodevsupport.freshdesk.com/zh-CN/support/home) 并在那里提出您的问题。


## 虚幻引擎 5 & SDK 版本
- 虚幻引擎 : 5.5.4

- Pico Unreal Integration SDK v3.2.0  


## Description:
  该示例实现了以下功能：
* 利用 PICO 身体跟踪数据驱动虚拟角色
* 踩踏产生烟花粒子
* 实现踩地鼠游戏
* 自定义身体姿势识别 
* 使用手柄右摇杆移动身体
